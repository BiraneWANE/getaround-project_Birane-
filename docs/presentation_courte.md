# Présentation courte

GetAround doit limiter les conflits créés par les retours tardifs entre deux locations successives.
Le projet quantifie plusieurs seuils de délai minimal et recommande ici un seuil de **120 minutes sur l'ensemble du parc**.
Cette option résout la majorité des cas problématiques tout en maintenant un impact commercial limité.

Le second volet du projet consiste à exposer un modèle de prédiction de prix via FastAPI.
Le dépôt final réunit donc une analyse produit, un modèle de machine learning, une API et une structure déployable.
