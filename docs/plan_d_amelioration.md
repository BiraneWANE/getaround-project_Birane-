- supprimer les formulations trop démonstratives ;
- harmoniser la langue visible en français ;
- rendre les titres et documents plus sobres.

## 2. Reconditionnement GitHub
- réécrire le README ;
- renommer les notebooks ;
- ajouter une documentation d'appui utile pour un lecteur externe.

- vérifier l'absence de secrets et de chemins locaux personnels ;
- proposer un `.gitignore` cohérent ;

- exécuter les tests API ;
- produire un notebook exécuté et un notebook sans outputs ;
- empaqueter le tout dans une arborescence simple à pousser sur GitHub.
