# Publication Git simple

## Vérifier les fichiers

```bash
git status
```

## Ajouter les fichiers

```bash
git add .
```

## Créer un commit

```bash
git commit -m "Prepare GitHub-ready GetAround project"
```

## Envoyer sur GitHub

```bash
git push
```

## Vérification finale

Après le push :
1. ouvrir le dépôt GitHub ;
2. vérifier le README ;
3. vérifier la présence des deux notebooks ;
4. vérifier que les dossiers `api`, `data`, `models` et `src` sont bien visibles.
